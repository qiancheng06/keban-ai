# 功能清单

## 优先级定义

| 标记 | 含义 | Demo 要求 |
|:----:|------|-----------|
| ✅ P0-真实 | Demo 必须包含，走通真实流程 | 上传 → AI 调用 → 结果展示，完整链路 |
| 🎨 P0-展示 | Demo 必须包含，仅 UI 展示 | 页面做出来，数据用 Mock / 预设示例，无后端逻辑 |
| ⏳ P1 | 有时间再做 | 视开发进度决定 |
| 📋 P2 | 策划书有但 Demo 不做 | 仅文档提及，不写代码 |

---

## ✅ P0-真实 — 核心功能（走真实 AI 链路）

| 模块 | 功能 | 说明 |
|------|------|------|
| 资料上传 | PPT/PDF 课件上传 | 支持从本地选择文件上传（不要求多格式） |
| AI 笔记整理 | 上传后 AI 自动生成结构化笔记 | 调用大模型 API，输出带标题分级的笔记 |
| 复习提纲 | 基于笔记生成复习大纲 | AI 标注高频考点和易错点 |
| 错题分析 | 文字录入错题，AI 分析 | 返回错误原因 + 关联知识点 + 推荐练习 |

## 演示故事线（推荐）

1. 打开小程序 → 看到 **首页仪表盘**（倒计时 + 每日一题）
2. 点击 **上传资料** → 选择 PPT → AI 生成 **笔记**
3. 笔记页面点击 **生成复习提纲**
4. 进入 **错题分析** → 录入一道错题 → AI 分析
5. 切换到 **AI 答疑** 页面 → 问一个问题 → 预设回答
6. 浏览 **知识点视频搜索** → 展示搜索结果
7. 进入 **学习搭子** 页面 → 展示匹配列表
8. 回到 **个人主页** → 展示学习成果概览

> 整个演示约 3-5 分钟，覆盖 ✅ P0-真实 和 🎨 P0-展示 的核心页面。
