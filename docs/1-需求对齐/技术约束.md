# 技术约束

## 一、项目性质约束

| 约束项 | 说明 |
|--------|------|
| 课程作业 | 《大学生创新创业基础》创业计划项目 |
| 时间窗口 | 学期内完成，预计 1-2 个月 |
| 团队技能 | 大学生团队，技术能力有限，优先选成熟低门槛方案 |
| 主交付物 | 项目策划书（docx 文档） |
| 程序定位 | 功能演示 Demo，非生产级产品 |

## 二、平台约束

| 约束项 | 说明 |
|--------|------|
| 前端平台 | **微信小程序** — 根据策划书，作为主要载体 |
| 兼容性 | 同时支持 iOS 和 Android 微信客户端 |
| 小程序限制 | 包体积 ≤ 2MB（主包），需注意代码分包 |
| 小程序限制 | 不能直接操作 DOM，使用 WXML 模板渲染 |
| 小程序限制 | 网络请求需配置合法域名白名单 |

## 三、技术选型约束（Demo 阶段）

| 层级 | 技术选型 | 理由 |
|------|----------|------|
| 前端 | 微信小程序原生框架 / WXML + WXSS + JS | 零门槛，无需额外构建工具 |
| 后端 | Node.js + Express（简化版） | 团队熟悉 JS，快速搭建 |
| 数据库 | 本地 JSON 文件 / SQLite | Demo 无需持久化到云，降低部署复杂度 |
| AI 能力 | 调用大模型 API（如 文心一言 / DeepSeek / GPT） | 直接调用 API，不自行训练模型 |
| 部署 | 本地运行 / 简单云服务器 | Demo 阶段只要能跑即可 |

## 四、成本约束

| 项目 | 预算建议 | 说明 |
|------|----------|------|
| AI API 调用 | ¥0（可用免费额度） | ChatGPT/DeepSeek 等有免费额度 |
| 小程序注册 | ¥0 | 个人开发者 ¥0，认证 ¥300（可不认证） |
| 云服务器 | ¥0（本地演示） | Demo 无需上云 |
| 域名/备案 | ¥0 | 小程序可不绑定域名（开发版） |

## 五、Demo 演示环境要求

- 演示手机：Android / iOS 均可，安装微信即可
- 演示方式：微信开发者工具模拟器 → 真机预览
- 网络要求：演示现场需有网络（调用 AI API）
- 容错方案：AI API 调用失败时应有降级展示（展示预设示例数据）

## 六、安全约束（Demo 可忽略项）

- ❌ 用户密码加密（微信授权代劳）
- ❌ HTTPS 证书（本地开发可跳过）
- ❌ 数据备份（Demo 数据可丢失）
- ❌ 隐私合规（Demo 不收集真实用户数据）

但**必须注意**：AI API Key 不能硬编码在前端代码中，需通过后端代理调用。

## 七、核心决策记录

| 决策 | 选项 | 结论 |
|------|------|------|
| AI 模型选型 | GPT-4o / DeepSeek-V3 / 文心一言 | **待定**（根据 API 免费额度确定） |
| Demo 数据方案 | 真实 AI 生成 / 预设 Mock 数据 | **待定**（看 API 调用稳定性） |
| 后端框架 | Express / Koa / 微信云开发 | **建议 Express**（灵活性最高） |
| 小程序组件库 | WeUI / Vant Weapp / 无 | **待定**（看团队 UI 能力） |
